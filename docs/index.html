로그 대신 읽어드림

매주 월요일, 서버 5대의 로그 7종을 사람이 직접 열어보던 점검을 메일 한 통으로 바꿨습니다. 수집·분류·리포트는 스크립트가, “그래서 이번 주 괜찮아?”라는 판단은 Claude가 첫 줄에 써 줍니다.

리포트는 두 가지로 볼 수 있습니다. 데모는 합성(가짜) 로그로 만든 것이고, 실제 운영은 운영 서버에서 나온 리포트에서 IP·도메인·계정 등 식별 정보를 마스킹한 것입니다. 두 리포트 모두 운영 중인 분석 코드로 만들었습니다.
운영 대상
Windows 1대 · Linux 4대
분석 로그
Nginx · Tomcat 3종 · L4 편차
실행
작업 스케줄러 · cron (주간/월간)
AI
Claude API 요약 (Python 3.6, SDK 없이)

Before 시간은 단계별 추정치: Windows 원격 접속·로그 3종 확인 15분 + Linux 4대 SSH·grep 20분 + 스캔 소음 걸러내고 장애 판단 10분 + L4 편차 계산·공유 메일 작성 10분.

Before — 사람이 직접

  • Windows 서버 원격 접속 → Nginx·Tomcat 로그 폴더 열기
  • Linux WEB 2대·WAS 2대 SSH 접속 → grep으로 에러 찾기
  • 스캐너 404 수백 건 사이에서 진짜 장애 골라내기
  • WEB1/WEB2 트래픽 편차는 계산기로

After — 월요일 아침 메일 한 통

  • 스케줄러가 직전 주 로그를 자동 수집·집계
  • 스캔 시그니처(FortiOS·WordPress·정찰성)는 자동으로 소음 처리
  • 맨 위에 Claude 요약: 정상 / 주의 / 위험 + 확인할 것 2~4줄
  • 사람은 “주의·위험”일 때만 상세 리포트를 열면 됨

리포트 메일 미리보기 AI 요약: 확인 중

메일로 받아보기

실제 운영 메일과 똑같은 HTML 본문 + 상세 리포트 ZIP이 발송됩니다.

어떻게 동작하나

1
수집
Windows는 로컬 폴더, Linux는 WEB1에서 SSH로 나머지 3대의 로그를 zgrep
2
분류
키워드·상태코드 집계, 알려진 스캔 시그니처와 refresh-token 401은 소음으로 분리
3
AI 요약
집계 수치 + 마스킹한 샘플 최대 15줄만 Claude에 보내 종합 판단과 조치 권고를 받음
4
발송
HTML 메일 본문 + 상세 리포트 ZIP 첨부

AI를 안전하게 붙인 방법

원문 로그를 보내지 않음

집계 수치와 ‘미분류’ 샘플 일부만 전송

마스킹

IP 뒤 두 자리(10.20.x.x)와 이메일을 가린 뒤 전송

실패해도 메일은 나감

키 없음·네트워크 차단·API 오류 시 AI 박스만 빠지고 기존 리포트 그대로
